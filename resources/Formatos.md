# Formatos de Contenido B2C — Sommos

Los formatos permiten adaptar el contenido al objetivo y al tipo de mensaje que se quiere comunicar. Este archivo es una guía de referencia con dos usos:

- **Para el planificador de contenidos:** elegir el formato de cada publicación (secciones 1 a 4).
- **Para la etapa de producción:** lineamientos para desarrollar cada pieza (sección 5). El planificador no desarrolla estos aspectos.

Los formatos válidos son únicamente **Post, Carrusel y Reel**. No agregar otros formatos.

---

## 1. Los tres formatos

### Post

Pieza gráfica estática.

**Usar para:**

- Comunicar una idea puntual.
- Destacar un beneficio o una característica.
- Explicar información breve.
- Generar interés sobre un tema.
- Recordar una acción.

**No usar cuando:** la idea necesita varios pasos o más contexto del que cabe en una sola pieza.

### Carrusel

Varias piezas gráficas que desarrollan una idea de manera progresiva.

**Usar para:**

- Explicar un tema paso a paso.
- Desarrollar información que no cabe en una sola pieza.
- Presentar varios beneficios o características.
- Resolver dudas frecuentes.
- Comparar o presentar diferentes situaciones.

**No usar cuando:** el mensaje es una sola idea simple (mejor un Post) o depende de mostrar una situación en movimiento (mejor un Reel).

### Reel

Contenido audiovisual corto y dinámico.

**Usar para:**

- Explicar una idea de manera sencilla.
- Mostrar situaciones cotidianas.
- Presentar el funcionamiento general del producto de forma visual.
- Resolver dudas.
- Generar interés y conexión con el público.

**No usar cuando:** el mensaje es información puntual que se entiende mejor en una pieza estática, o cuando no hay una situación o secuencia que aprovechar en video.

---

## 2. Cómo elegir el formato

Elegir según el objetivo, el tipo de información, la complejidad del mensaje, el público y la capacidad del formato para comunicar la idea con claridad. **No usar un formato solo por variedad:** debe responder a una necesidad de comunicación.

Como los tres formatos pueden servir para varios objetivos, usar esta guía para desempatar:

| Si el mensaje... | Formato |
|---|---|
| Es **una sola idea**, breve y directa | Post |
| Tiene **varias partes, pasos o puntos** que se desarrollan en orden | Carrusel |
| Se entiende mejor **mostrando una situación cotidiana o una secuencia** | Reel |

Referencia rápida por objetivo (orientativa, no rígida):

| Objetivo | Formato habitual |
|---|---|
| Educar | Post o Carrusel |
| Generar awareness | Reel o Post |
| Explicar el producto o su funcionamiento | Carrusel o Reel |
| Mostrar un beneficio | Post o Carrusel |
| Resolver una objeción o duda frecuente | Carrusel o Post |
| Generar interés, identificación | Reel |
| Generar registros o descargas | Post o Carrusel |
| Recordar una acción | Post |

---

## 3. Variedad dentro del mes

- Combinar formatos a lo largo del mes, siempre que cada uno responda a su objetivo.
- Considerar que un **Reel requiere más producción** que un Post o un Carrusel; no basar todo el calendario en Reels sin una razón.
- Evitar repetir el mismo formato en publicaciones consecutivas, salvo que el contenido lo justifique.

---

## 4. Relación con los pilares

Orientación habitual, no rígida:

| Pilar | Formatos que suelen funcionar |
|---|---|
| Educación | Post, Carrusel |
| Necesidad y objetivos | Reel, Carrusel |
| Producto y funcionamiento | Carrusel, Reel, Post |
| Confianza y experiencia | Post, Carrusel |

---

## 5. Lineamientos de desarrollo (etapa de producción)

Estos lineamientos aplican cuando la pieza se desarrolla, no al planificar. El planificador no debe incluir copy, guion, número de láminas ni detalles visuales.

### Personas reales

En Post, Carrusel y Reel, siempre que sea pertinente, usar **personas reales** para acercar el contenido y facilitar la identificación con situaciones cotidianas.

Usar personas reales en una pieza **no equivale a un testimonio**: los testimonios, casos o experiencias de usuarios solo se usan si existen en el contexto del proyecto.

### Reglas para Reels

- Priorizar el uso de **personas reales**.
- Usar **voz en off** para desarrollar el mensaje.
- Incluir **subtítulos** durante todo el Reel.
- Mantener una estructura clara y fácil de seguir.
- Adaptar la duración al contenido, sin alargarlo innecesariamente.
- Usar recursos visuales que acompañen y refuercen el mensaje.
